# sistema-biblioteca
Sistema de Biblioteca para cadastro de livros, alunos e controle de empréstimos.
# Projeto: Sistema de Biblioteca

## 1. Descrição

O sistema de biblioteca serve para cadastrar livros e alunos, controlar empréstimos e registrar devoluções.

## 2. Requisitos funcionais

- RF01 – Cadastrar livros.
- RF02 – Cadastrar alunos.
- RF03 – Consultar livros cadastrados.
- RF04 – Registrar empréstimos de livros.
- RF05 – Registrar devoluções de livros.
- RF06 – Consultar livros disponíveis.

## 3. Requisitos não funcionais

- RNF01 – O sistema deve ser fácil de usar.
- RNF02 – O sistema deve ter uma tela simples.
- RNF03 – O sistema deve salvar os dados cadastrados.

## 4. Objetivo

Facilitar a organização da biblioteca, ajudando no controle dos livros, alunos e empréstimos.
